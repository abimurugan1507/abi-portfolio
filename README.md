# ABI M — Portfolio v2

A responsive portfolio inspired by the reference layout shared by Abi.

## Main title
Aspiring Data Analyst & Frontend Developer

## Files
- `index.html` — portfolio structure and content
- `style.css` — cream, olive-green and responsive design
- `script.js` — mobile navigation, dark mode, scroll reveal and active navigation

## Run locally
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Before publishing
- Confirm the HCL and AlphaSai internship descriptions and dates.
- Add a resume PDF if you want a resume-download button.
- Add the Event Registration System repository URL when it is published.
- Review your contact and profile links.
- The Student Performance dashboard artwork is an illustrative mockup, not a screenshot of the live dashboard.
